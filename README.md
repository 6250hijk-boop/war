## 🌐 오프라인 한·영 교차 검색 & 한국어 응답 파이프라인

1. **한국어 질문 입력**: 사용자가 한국어로 질문합니다 (예: *"핵폭발 후 72시간 행동요령은?"*, *"오염된 물을 식수로 소독하는 법은?"*, *"지혈대 사용법 알려줘"*, *"보우라인 매듭 묶는 법은?"*).

3. **한글 + 영문 PDF 동시 MMR 검색**: 한글 문서와 영문 문서를 동시에 검색합니다.
4. **100% 한국어 결과 출력**: 영문 매뉴얼에서 찾은 내용도 한국어로 번역·통합하여 **`🎯 핵심 답변 → 💡 원리 및 상세 해설 → ✅ 단계별 생존·행동 수칙 → ⚠️ 주의사항 및 출처`**로 출력합니다.
